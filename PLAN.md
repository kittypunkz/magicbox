## 🚨 Phase 1: Security & Stability

**Goal:** Fix critical vulnerabilities and clean up technical debt.
**Timeline:** 1–2 days

### 1.1 Enforce Auth on All Data Routes
- **Files:** `backend/src/routes/notes.ts`, `folders.ts`, `search.ts`
- **Action:** Add `authMiddleware` to all routes (currently have TODO comments)
- **Risk:** Currently anyone with the API URL can read/write notes without login

### 1.2 Remove Test Mode Bypass
- **File:** `frontend/src/App.tsx` (~line 30)
- **Action:** Remove `VITE_TEST_MODE` bypass from `ProtectedRoute`
- **Risk:** If `VITE_TEST_MODE=true` is set in production, auth is disabled entirely

### 1.3 Add React Error Boundaries
- **File:** `frontend/src/App.tsx` (new component)
- **Action:** Wrap routes in error boundary, show fallback UI on crash
- **Risk:** One uncaught error = blank screen for users

### 1.4 Clean Dead Code
- **Files to remove:**
  - `frontend/src/components/BlockNoteEditor.tsx`
  - `frontend/src/components/EditorSearch.tsx`
- **Action:** Delete files, remove any imports
- **Risk:** Ships unused code to production, confuses developers

### 1.5 Update Schema to Match D1
- **File:** `database/schema.sql`
- **Action:** Add missing columns (`bookmark_url`, `bookmark_title`, `is_pinned`, auth tables)
- **Risk:** New developers can't set up from this file; schema drift

### 1.6 Add D1 Migrations
- **Location:** `backend/migrations/`
- **Action:** Create numbered migration files that match current D1 state
- **Risk:** No reproducible setup; schema changes are manual

## 🟢 Phase 3: Features

**Goal:** Add value for users. Prioritized by impact.
**Timeline:** Variable per feature

### 3.1 Soft Delete / Trash (Est: 3h)
- Add `deleted_at` column to notes
- "Trash" view showing deleted notes
- "Restore" and "Permanently Delete" actions
- Auto-purge after 30 days

### 3.2 Tags / Labels (Est: 4h)
- New `tags` table + `note_tags` junction table
- Tag picker in note editor
- Filter by tag in sidebar
- Tags shown on note cards

### 3.3 Multi-User Support (Est: 8h)
- User registration flow
- Each user has their own folders/notes
- Shared folders (optional, future)
- User management page

### 3.4 Keyboard Shortcuts (Est: 2h)
- `Ctrl+N` — New note
- `Ctrl+K` — Search
- `Ctrl+/` — Show shortcuts help
- `Esc` — Close modal / go back

### 3.5 Note Templates (Est: 3h)
- Pre-built templates (meeting notes, todo list, journal)
- "New from Template" option in create modal
- User-defined templates (future)

### 3.6 Version History (Est: 4h)
- `note_versions` table
- Save version on each edit (debounced)
- "View History" in note editor
- Restore previous version
